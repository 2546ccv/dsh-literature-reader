# 浏览器扩展（任意网页使用文献助手）

> 在**任何网页**里（浏览器内 PDF、arXiv、Google Scholar、博客、WPS 网页版等）选中文字，浮窗即可解释/翻译——不再需要把文件导入 DSH 面板。

## 原理

```
┌─ 任意网页 ──────────────┐      ┌─ 浏览器扩展 ───────────────┐      ┌─ DSH 后台 (本机) ──────────┐
│ 选中文字 → 浮窗          │ ───▶ │ content.js 收集选区          │ ───▶ │ background.js 转发          │
│ 📖解释 🌐翻译            │      │                            │      │  → http://127.0.0.1:3080   │
└─────────────────────────┘      └────────────────────────────┘      │    /lit-http/ask            │
                                                                    │  → ctx.llm.stream() 一次性   │
                                                                    └─────────────────────────────┘
```

- 扩展的 `background.js` 把请求转发到本机 DSH 的 HTTP 端点 `/lit-http/ask`（插件 host 半注册的**后台服务**）。
- 复用你 DSH 里已配置的 **Provider / Model / token 上限 / system prompt**——不单独配 Key，token 策略与面板内一致（一次性、不入会话历史）。
- 要求：**DSH web 正在本机运行**（127.0.0.1:3080）。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge）
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本目录：`extension/`
4. 完成。现在任意网页选中文字就会弹出浮窗

> 若修改了 `extension/` 里的代码，回到扩展管理页点 **刷新** 按钮即可。

## 快捷键

| 按键 | 作用 |
|---|---|
| `Alt+E` | 解释当前选中文字 |
| `Alt+T` | 翻译当前选中文字 |
| `Esc` | 关闭浮窗 |

## 设置

扩展默认使用 DSH host 插件配置里的 Provider / Model。如需覆盖，在扩展管理页 →「扩展程序详情」→「扩展程序选项」（本扩展暂未提供选项页，可在 `chrome.storage.sync` 中设置 `provider` / `model` 键；后续版本会补选项页）。

## 常见问题

**Q: 浮窗提示「无法连接 DeepSeek Harness 后端」？**
A: 确认 dsh web 正在运行（浏览器打开 http://127.0.0.1:3080 能看到界面）；确认插件已安装（设置 → 插件里能看到 literature-reader）。

**Q: 在浏览器内置 PDF 查看器（chrome:// 页面）里选中没反应？**
A: 浏览器安全限制：扩展的 content script 无法注入 `chrome://`、扩展商店等受限页面，也不覆盖内置 PDF 阅读器。这种情况请改用 DSH 面板「打开 PDF」导入，或把 PDF 在普通网页（如 arXiv）中打开。

**Q: 会污染我的 DSH 会话吗？**
A: 不会。`/lit-http/ask` 与面板内的 `/lit` 走同一套一次性调用逻辑，不入会话历史、不占上下文。
